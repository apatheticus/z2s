## Frozen system

### Palette

| Role | Hex | Notes |
| --- | --- | --- |
| background       | `#F0F0EA` | page canvas — warm paper |
| surface          | `#FFFFFF` | cards / panels |
| ink              | `#0D0D0C` | primary text |
| muted            | `#545452` | secondary text, eyebrows |
| rule             | `#C2C2BC` | hairline cell borders |
| accent-primary   | `#B84E2E` | the one focal cell, and the chain motif |
| accent-secondary | `#3E587E` | the slate blue the published set uses for links |

Product tokens → doc roles:

| Product token | Value | Doc role |
| --- | --- | --- |
| `--surface-page` / `--gray-50` | `#F0F0EA` | background |
| `--surface-card` / `--gray-0` | `#FFFFFF` | surface |
| `--text-body` / `--gray-900` | `#0D0D0C` | ink |
| `--text-secondary` / `--gray-600` | `#545452` | muted |
| `--border-strong` / `--gray-300` | `#C2C2BC` | rule |
| `--vermillion-600` | `#B84E2E` | accent-primary |
| `--color-primary` / `--blue-600` | `#3E587E` | accent-secondary |

Gap-fills, marked as such rather than claimed as brand: `--border-strong` is used
for the hairline where the published stylesheet would use `--border-default`
(`#D9D9D3`), because the lighter tint is invisible on white at this scale; and
`accent-primary` takes `--vermillion-600` rather than the published
`--color-accent` (`--vermillion-500`, `#D0603C`), because white text on the
lighter tint measures 3.87:1 and misses the contrast floor.

Diagram-grammar bindings, for any later visual that carries `data-diagram`:
`paper` → background, `surface` → surface, `ink` → ink, `muted` → muted,
`rule` → rule, `accent` → accent-primary, `link` → accent-secondary.

### Typography

| Role | Stack |
| --- | --- |
| display | `-apple-system, BlinkMacSystemFont, "Segoe UI", sans-serif` |
| body    | `-apple-system, BlinkMacSystemFont, "Segoe UI", sans-serif` |
| mono    | `ui-monospace, SFMono-Regular, Menlo, monospace` |

The published document set loads Instrument Sans and JetBrains Mono over the
network. A committed SVG may not reference anything remote, so visuals use system
stacks instead. This is a deliberate divergence from the site, not a drift.

### Shape language

Radius 16 on every cell, 12 on anything nested inside one. Hairline borders at
1 unit; no shadows. Spacing unit 20, which is also the single gutter value.

### Motif

A row of small squares, one lit at a time, advancing left to right — the chain of
documents, each one waiting on the one before it. It appears once per visual, in
the focal cell, never as background texture.

### Composition rules

Compact-technical. One bento grid per visual, unequal spans, every cell doing one
job. Important content stays 40 units clear of the edges.

### Motion rules

- Seamless ambient loops, 8–14s each; state at t=D equals state at t=0.
- Loop length declared once as `data-loop-s`; every duration divides it evenly.
- Ease character: `cubic-bezier(.4,0,.2,1)`; calm, purposeful.
- No strobing, no flicker, no idle bobbing.
- Every animated visual carries a `@media (prefers-reduced-motion: reduce)` block
  that stops all motion and leaves a legible still.

### Style

| Field | Value |
| --- | --- |
| Slug | `bento-grid` |
| Source | catalog |
| Primary axis | composition |

- **Intent** — unequal cells packed into one tight grid, each cell doing exactly
  one job. Chosen because the hero has to hold six unrelated facts at once.
- **Palette treatment** — quiet ground, cells in `surface`, exactly one cell
  promoted to `accent-primary` as the focal point.
- **Shape language** — radius 16 on every cell, 12 nested; one gutter value (20)
  everywhere; spans of 1, 2 or 3 columns and nothing between.
- **Material / depth** — a 1-unit hairline border in `rule`. No shadows anywhere.
- **Type treatment** — three steps per cell: eyebrow 20/600 uppercase tracked
  `+1.4` in `muted`; label 24/600; value 48/700. Units ride the value as a smaller
  `<tspan>`. System sans throughout, sentence case outside the eyebrow.
- **Motion character** — one cell moves at a time. The grid itself is static;
  that stillness is what makes the moving cell read as live.
- **SVG recipes** — six columns at `x = 40 + col × 190`,
  `w = span × 170 + (span − 1) × 20`; negative `animation-delay` to stagger the
  chain squares within one shared duration.
- **Relaxations** — none. White cells on a light ground need the hairline, which
  is exactly what the UI-contrast gate measures, so it is left to measure it.
- **Never** — varying gutters or radius, a nested radius below 12, a second
  accent-filled cell, no focal cell at all, three lines of body text in one cell,
  more than two cells animating at once, or a grid uniform enough to be a table.
